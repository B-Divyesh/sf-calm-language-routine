See how your study data is handled

Last updated September 5, 2026.

Study data stays in this browser

Quiet Loop stores cards, archive reasons, settings, reviews, and reflections in browser IndexedDB.

It does not create an account or send study data to another service.

Demo data is separate

The demo uses a separate IndexedDB database. It does not read or change your real cards.

Exports and deletion

You can export cards as CSV or create a JSON backup from Data controls.

Delete all local data removes Quiet Loop data from the current database. Clearing browser site data also removes it.

Purchase licenses

A restored license token is stored in local storage. Quiet Loop sends that token only to Sociobot for validation.

A license is checked at most once daily. Sociobot and Dodo handle payment as merchant of record.

No tracking

Quiet Loop loads no advertising, behavioral analytics, third-party script, or external font.

The app works offline after the first successful visit.

Privacy requests

Use Delete all local data to remove study data. Contact the operator through the product listing at sociobot.in for other requests.

Review a fixed daily set and archive stale cards.
